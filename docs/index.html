Capabilities

Everything your screen holds,
understood by AI

ScreenSiri combines screen capture, speech recognition, and GPT-4o to give you a truly context-aware assistant.

🎙️

Voice Input

Tap once and speak. On-device speech recognition (SFSpeechRecognizer) converts your voice to text with low latency.

📸

Screen Awareness

Captures the current screen via ReplayKit and sends it as context so the AI knows exactly what you're looking at.

💬

Text Chat

Prefer typing? Use the full-screen chat interface for longer conversations or when voice isn't appropriate.

🔐

Secure Key Storage

Your OpenAI API key is stored in iOS Keychain — never in UserDefaults or plain storage.

⚡️

Siri Integration

Add a Siri shortcut so you can launch ScreenSiri hands-free with a phrase of your choosing.

🌊

Streaming Responses

Responses stream token-by-token so you see the answer as it's generated — no waiting for the full reply.

Architecture

How it works

A SwiftUI overlay app built on top of iOS's broadcast APIs.

01

Tap the floating orb

A persistent floating button sits over all apps. One tap opens the assistant panel as a translucent overlay.

02

Speak or type your question

Voice input uses AVAudioEngine + SFSpeechRecognizer. Text chat opens a full keyboard interface.

03

Screen context is captured

ReplayKit grabs a screenshot of the current app, which is encoded and sent alongside your question to GPT-4o Vision.

04

Streaming response

GPT-4o streams its reply back. The panel animates and displays tokens in real time. The assistant remembers the full conversation history.
